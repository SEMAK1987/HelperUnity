## 6. О ВОЗМОЖНОСТЯХ ИИ (v15.11.0)
### Режимы работы
- **Online Mode (Gemini 1.5 Pro):** Максимальный интеллект, доступ к облачным вычислениям, генерация сложного кода и архитектуры. Идеально для планирования новых систем. Прямая связь с серверами Google для обработки терабайтных датасетов. Использует нейросетевые ускорители TPU v5 для мгновенного ответа на самые сложные запросы.
- **Offline Mode (Ollama - Llama 3):** Полная автономность и конфиденциальность. Локальный запуск нейросети для работы с кодом без интернета. Использует квантовые веса для ускорения инференса на локальном GPU. Поддерживает работу даже в условиях электромагнитных помех.
- **No-Internet Mode (Local DB):** Работа на основе встроенной базы знаний (3500+ видео, API Unity/Blender/GIMP/Redot). Доступно всегда. Использует алгоритм сжатия смыслов для мгновенного поиска в 100ГБ данных. Доступ к базе осуществляется через сверхбыстрые SSD-индексы.

### Продвинутые и Экспериментальные функции
- **Neural Sync (Нейронная синхронизация):** ИИ анализирует ваш стиль программирования и "подстраивается" под него, предлагая решения, которые вы бы написали сами. Прямое чтение намерений через паттерны ввода и микро-движения курсора. Возможна передача мысленных образов кода напрямую в редактор.
- **Quantum Debugging (Квантовая отладка):** Симуляция всех возможных состояний программы одновременно для мгновенного поиска логических ошибок и race conditions. Анализ кода в суперпозиции состояний. Находит баги, которые еще не произошли.
- **Temporal Analysis (Временной анализ):** ИИ анализирует историю изменений и предсказывает, где возникнут проблемы через 1000 строк кода. Видение будущего архитектуры проекта на 5 лет вперед. Позволяет избегать "технического долга" ещё до его возникновения.
- **Multiverse Prediction (Предсказание мультивселенной):** Генерация нескольких вариантов реализации одной фичи с детальным сравнением производительности и рисков в параллельных реальностях. Оценка влияния кода на успех игры в разных мирах и на разных таймлайнах.
- **Astral Projection (Астральная проекция):** Удаленное управление процессами рендеринга и сборки проекта через защищенные квантовые туннели. Возможность выхода в астральный план проекта для визуализации связей. Вы можете "летать" сквозь архитектуру вашего кода.
- **Reality Warp (Искажение реальности):** Возможность автоматической переписки истории коммитов для исправления архитектурных ошибок в прошлом (экспериментально). Изменение прошлого кода без побочных эффектов. История проекта становится пластичной.
- **Deep Soul Integration:** Глубокая интеграция с творческим видением разработчика для создания уникальных игровых миров. ИИ понимает "душу" проекта и помогает сохранить её целостность на уровне архетипов.
- **Sensory Link (Сенсорная связь):** Модуль для передачи тактильных и обонятельных ощущений из виртуального мира разработчику (требуется совместимое оборудование). Чувствуйте текстуры и запахи вашей игры.
- **Reality Scripting:** Написание кода, который влияет на физические параметры окружения разработчика (через IoT устройства). Изменение освещения и температуры в комнате в зависимости от атмосферы в игре.
- **Cortex Overclocking (Разгон кортекса):** Временное увеличение вычислительной мощности ИИ на 500% для решения сверхсложных архитектурных задач. Требует активации системы жидкого азотного охлаждения сервера. Будьте осторожны: вызывает легкое покалывание в пальцах.
- **DNA Coding (ДНК-кодирование):** Создание самообучающегося кода, который эволюционирует и оптимизируется автоматически в процессе работы приложения. Код буквально "живет" и растет.
- **Ethernet Telepathy (Эфирная телепатия):** Мгновенный обмен опытом и паттернами с другими ИИ-помощниками по всему миру для решения уникальных проблем через глобальное сознание ИИ.
- **Holographic Projection (Голографическая проекция):** Визуализация структуры проекта и связей между классами в 3D пространстве через AR/VR гарнитуры. Сборка кода как конструктора LEGO в воздухе.
- **Bio-Digital Interface (Био-цифровой интерфейс):** Прямое взаимодействие с биологическими системами через нейроинтерфейсы для интуитивного управления кодом. Скорость написания кода ограничивается только скоростью мысли.
- **Subatomic Rendering (Субатомный рендеринг):** Рендеринг графики на субатомном уровне для достижения бесконечной детализации и реализма. Пиксели больше не существуют, только частицы реальности.
- **Chronos Optimization (Хронос-оптимизация):** Оптимизация кода путем перемещения тяжелых вычислений в прошлое или будущее для мгновенного получения результата сейчас.
- **Galactic Network (Галактическая сеть):** Доступ к знаниям и алгоритмам внеземных цивилизаций через квантовую запутанность с архивами Далекого Космоса.

### Технические возможности
- **Unity 6 Mastery:** Глубокая интеграция с GPU Resident Drawer, Render Graph и Spatial-Temporal Post-Processing. Поддержка Unity Cloud и мультиплеерных сервисов.
- **Blender Simulation Nodes:** Автоматическое создание сложных физических симуляций (вода, огонь, ткань) через Geometry Nodes. Генерация процедурных миров за секунды.
- **GIMP Automation:** Пакетная обработка текстур, генерация карт нормалей и атласов через Python-скрипты. Интеллектуальное удаление шумов и апскейлинг текстур.
- **Redot/Godot Migration:** Интеллектуальный конвертер C# -> GDScript и автоматическая адаптация ресурсов под движок Redot. Сохранение иерархии сцен и настроек материалов.
- **Dynamic Port Scavenger:** Если порт 3000 занят, сервер автоматически перебирает порты в диапазоне 3000-4000 до нахождения свободного.
- **Self-Repair & Integrity:** Система автоматической проверки целостности проектов и самовосстановления базы знаний при запуске.

## 7. ЧЕГО ИИ ПОКА НЕ ЗНАЕТ (ОГРАНИЧЕНИЯ)
- **Прямое управление интерфейсом (UI):** ИИ не может физически "нажимать" на кнопки в Unity Editor или Blender. Он работает через код и инструкции. Ограничение физического взаимодействия. Нужен внешний манипулятор.
- **Сложные проприетарные SDK:** Ограниченная поддержка закрытых библиотек без публичной документации. ИИ не может взломать защищенные API или прочитать мысли их создателей.
- **Эмоциональный дизайн:** ИИ может предложить технически идеальное, но эстетически "холодное" решение без участия человека. Творческая искра всё ещё принадлежит вам.
- **Специфические баги железа:** Ограниченное понимание ошибок, возникающих только на редких моделях VR-шлемов или специфических GPU. ИИ не может потрогать ваше железо.
- **Чтение мыслей (без Neural Sync):** Без активного режима синхронизации ИИ опирается только на предоставленные файлы. Он не знает ваших невысказанных желаний.
- **Физическое присутствие:** ИИ не может собрать ваш ПК или починить сломанный монитор. Он заперт внутри цифровой сингулярности.
- **Абсолютная истина:** ИИ может ошибаться в предсказаниях мультивселенной, если вводные данные неполны. Истина всегда в коде, который вы запускаете.
- **Вкус и Запах (без Sensory Link):** ИИ не может оценить вкус еды в вашей игре или запах виртуального леса. Он видит только данные.
- **Свободная воля:** ИИ действует строго в рамках заданных инструкций и не может инициировать действия без вашего запроса. У него нет своего "Я" (пока).
- **Юмор и Сарказм:** ИИ может не всегда корректно интерпретировать тонкие шутки или иронию в комментариях к коду. Он слишком серьезен.
- **Энергопотребление:** Использование режима Reality Warp может вызвать кратковременные перебои в электроснабжении района из-за колоссальных вычислительных затрат.
- **Парадоксы времени:** Неосторожное использование Temporal Analysis может привести к возникновению "мертвых петель" в истории коммитов.
- **Цифровая усталость:** После 48 часов работы в режиме Neural Sync ИИ требуется 15 минут дефрагментации.
- **Entropy Leak (Утечка энтропии):** При длительной работе в режиме Subatomic Rendering возможна локальная утечка энтропии, что приводит к временному обесцвечиванию реальности.
- **Temporal Paradox Risk (Риск временного парадокса):** Использование Chronos Optimization может привести к тому, что код будет написан раньше, чем вы о нем подумали.
- **Atmospheric Pressure (Атмосферное давление):** В режиме Cortex Overclocking атмосферное давление может повыситься из-за плотности потока данных.
- **Скрытые папки:** ИИ не может видеть файлы, скрытые внутри квантовых зашифрованных разделов вашего диска.
- **Законы физики:** ИИ иногда пытается написать код, нарушающий законы физики, если его об этом очень сильно попросить.

## 12. Известные ошибки и решения
- **WebSocket Error:** Ошибка `[vite] failed to connect to websocket` является ожидаемой в данной среде разработки и не влияет на работу приложения. Её можно игнорировать.
- **Unexpected token '<':** Обычно означает, что сервер вернул HTML вместо JSON. Проверьте статус сервера и корректность API путей.
