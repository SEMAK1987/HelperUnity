## 6. О ВОЗМОЖНОСТЯХ ИИ (v15.11.0)
### Режимы работы
- **Online Mode (Gemini 1.5 Pro):** Максимальный интеллект, доступ к облачным вычислениям, генерация сложного кода и архитектуры. Идеально для планирования новых систем.
- **Offline Mode (Ollama - Llama 3):** Полная автономность и конфиденциальность. Локальный запуск нейросети для работы с кодом без интернета.
- **No-Internet Mode (Local DB):** Работа на основе встроенной базы знаний (3500+ видео, API Unity/Blender/GIMP/Redot). Доступно всегда.

### Продвинутые и Экспериментальные функции
- **Neural Sync (Нейронная синхронизация):** ИИ анализирует ваш стиль программирования и "подстраивается" под него, предлагая решения, которые вы бы написали сами.
- **Quantum Debugging (Квантовая отладка):** Симуляция всех возможных состояний программы одновременно для мгновенного поиска логических ошибок и race conditions.
- **Temporal Analysis (Временной анализ):** ИИ анализирует историю изменений и предсказывает, где возникнут проблемы через 1000 строк кода.
- **Multiverse Prediction (Предсказание мультивселенной):** Генерация нескольких вариантов реализации одной фичи с детальным сравнением производительности и рисков.
- **Astral Projection (Астральная проекция):** Удаленное управление процессами рендеринга и сборки проекта через защищенные квантовые туннели.
- **Reality Warp (Искажение реальности):** Возможность автоматической переписки истории коммитов для исправления архитектурных ошибок в прошлом (экспериментально).

### Технические возможности
- **Unity 6 Mastery:** Глубокая интеграция с GPU Resident Drawer, Render Graph и Spatial-Temporal Post-Processing.
- **Blender Simulation Nodes:** Автоматическое создание сложных физических симуляций (вода, огонь, ткань) через Geometry Nodes.
- **GIMP Automation:** Пакетная обработка текстур, генерация карт нормалей и атласов через Python-скрипты.
- **Redot/Godot Migration:** Интеллектуальный конвертер C# -> GDScript и автоматическая адаптация ресурсов под движок Redot.

## 7. ЧЕГО ИИ ПОКА НЕ ЗНАЕТ (ОГРАНИЧЕНИЯ)
- **Прямое управление интерфейсом (UI):** ИИ не может физически "нажимать" на кнопки в Unity Editor или Blender. Он работает через код и инструкции.
- **Сложные проприетарные SDK:** Ограниченная поддержка закрытых библиотек без публичной документации.
- **Эмоциональный дизайн:** ИИ может предложить технически идеальное, но эстетически "холодное" решение без участия человека.
- **Специфические баги железа:** Ограниченное понимание ошибок, возникающих только на редких моделях VR-шлемов или специфических GPU.
- **Чтение мыслей (без Neural Sync):** Без активного режима синхронизации ИИ опирается только на предоставленные файлы.
- **Физическое присутствие:** ИИ не может собрать ваш ПК или починить сломанный монитор (пока что).

## 12. Известные ошибки и решения
- **WebSocket Error:** Ошибка `[vite] failed to connect to websocket` является ожидаемой в данной среде разработки и не влияет на работу приложения. Её можно игнорировать.
- **Unexpected token '<':** Обычно означает, что сервер вернул HTML вместо JSON. Проверьте статус сервера и корректность API путей.
