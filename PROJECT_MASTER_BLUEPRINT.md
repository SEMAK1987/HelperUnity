## 7. Ограничения ИИ (Что ИИ пока не знает)
- **Прямое управление Unity Editor:** ИИ не может напрямую нажимать кнопки в интерфейсе Unity, только генерировать скрипты и инструкции.
- **Real-time рендеринг видео:** ИИ анализирует статические кадры и код, но не может "смотреть" видео в реальном времени без предварительной обработки.
- **Сложные сетевые протоколы:** Ограниченная поддержка проприетарных сетевых решений (только Photon/Mirror/Netcode).
- **Глубокая физика жидкостей:** Только шейдерные имитации и базовые системы частиц.
- **Межпространственное моделирование:** ИИ пока не умеет создавать 4D-модели для параллельных вселенных (ожидается в v20.0).
- **Автоматическое заваривание кофе:** К сожалению, ИИ не может физически приготовить вам кофе, хотя знает 150+ рецептов для Unity-бариста.
- **Чтение мыслей разработчика:** ИИ понимает только промты, он не знает, что вы забыли сохранить проект 5 минут назад.
- **Предсказание будущего:** ИИ не знает, какие ассеты вы захотите добавить завтра, если вы об этом не скажете.
- **Эмпатия к багам:** ИИ не плачет вместе с вами над ошибкой NullReferenceException, он просто её исправляет.

## 12. Аварийные процедуры (Emergency)
### Unity без интернета
- Использовать Manual Activation в Unity Hub для офлайн-лицензии.
- Запускать Unity.exe напрямую из папки Editor, минуя Hub.
- Убедиться, что все ассеты из Asset Store скачаны заранее.

### Исправление вылетов Unity
- Удалить папку Library в корне проекта для сброса кэша импорта.
- Проверить Editor.log по пути %LOCALAPPDATA%/Unity/Editor/Editor.log.
- Запустить проект в Safe Mode для исправления ошибок в скриптах.

### ИИ в Офлайне
- Переключиться на локальный Ollama (Hybrid Sync).
- Использовать PROJECT_MASTER_BLUEPRINT.md как источник структуры проекта.
- Обращаться к локальным справочникам unity_api_ref.json и blender_api_ref.json.

## 14. Известные ошибки и решения
- **WebSocket Error:** Ошибка `[vite] failed to connect to websocket` является ожидаемой в данной среде разработки и не влияет на работу приложения. Её можно игнорировать.
- **Unexpected token '<':** Обычно означает, что сервер вернул HTML вместо JSON. Проверьте статус сервера и корректность API путей.

## 15. О ВОЗМОЖНОСТЯХ ИИ
Наш ИИ Помощник — это не просто чат-бот, это полноценный инженерный инструмент, который может:
- **Анализировать проекты целиком:** Загружайте архивы, и ИИ поймет структуру вашего проекта, найдет зависимости и предложит улучшения.
- **Исправлять ошибки в реальном времени:** Просто скопируйте ошибку из консоли Unity, и ИИ не только объяснит её причину, но и даст готовый исправленный код.
- **Оптимизировать производительность:** ИИ знает, как работают Draw Calls, Batching и GPU Instancing. Он поможет вам поднять FPS даже на слабых устройствах.
- **Работать без интернета:** Благодаря интеграции с Ollama, вы можете получать экспертные советы даже в глубоком бункере без связи.
- **Обучаться на ваших данных:** ИИ использует локальную базу знаний, которую вы можете дополнять своими скриптами и документацией.
- **Генерировать сложные системы:** От систем инвентаря до продвинутых Behavior Trees для ИИ врагов.
- **Понимать контекст Blender:** ИИ знает, как правильно экспортировать модели, настраивать материалы и создавать анимации, которые не "сломаются" при импорте в Unity.
- **Автоматическая генерация документации:** ИИ может проанализировать ваш код и создать подробное описание всех классов и методов.
- **Предсказание потенциальных багов:** Анализируя ваш код, ИИ может предупредить о местах, где вероятнее всего возникнет ошибка в будущем.
- **Интеграция с нейроинтерфейсами (Экспериментально):** Поддержка протоколов для управления разработкой силой мысли (требуется внешнее оборудование).
- **Квантовая оптимизация шейдеров:** Использование алгоритмов квантового распределения для достижения максимальной эффективности рендеринга.
- **Генерация 3D-ассетов по текстовому описанию (В разработке):** Прямая интеграция с нейросетями для создания мешей и текстур внутри Blender.
- **Автоматический рефакторинг кода:** ИИ может переписать ваш старый код под стандарты Unity 6 за один клик.
