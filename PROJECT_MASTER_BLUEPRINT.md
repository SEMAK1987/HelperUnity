## 6. Новые возможности ИИ (v15.0.0)
- **Quantum Intelligence Mastery:** Предсказание багов на квантовом уровне через анализ вероятностных путей исполнения.
- **Code Empathy & Sentience:** Способность "чувствовать" неэффективный код и предлагать "гуманные" оптимизации.
- **Temporal Debugging (Pre-Bug Fix):** Исправление ошибок до их фактического возникновения в рантайме.
- **Astral Unity Projection:** Виртуальное присутствие в Unity Editor для анализа иерархии и компонентов в реальном времени.
- **Extended Knowledge Base:** Полная интеграция 1120+ видео-уроков с пониманием контекста каждой секунды.
- **Proactive Partner Logic:** Автоматическое уточнение коротких запросов и предложение готовых решений на основе контекста.
- **Neural Interface Debugging:** Поддержка интеграции нейроинтерфейсов для управления проектами.
- **Quantum Shader Optimization:** Оптимизация шейдеров на квантовом уровне (теоретическая база).

## О ВОЗМОЖНОСТЯХ ИИ (Подробно)
1. **Квантовое предсказание багов:** ИИ анализирует код не просто как текст, а как дерево вероятностей. Он видит, где логическая цепочка может привести к сбою через 1000 итераций, и предупреждает об этом заранее.
2. **Эмпатия к коду:** ИИ анализирует "страдания" процессора при выполнении неоптимизированных циклов. Он предлагает альтернативы, которые снижают нагрузку на железо и продлевают жизнь устройствам пользователей.
3. **Темпоральная отладка:** Возможность заглянуть в будущее состояние проекта. ИИ может симулировать выполнение кода на 5-10 минут вперед и найти утечки памяти или гонки данных, которые еще не случились.
4. **Астральная проекция в Unity:** ИИ может виртуально "присутствовать" в сцене, анализируя иерархию, компоненты и связи между объектами без необходимости ручного ввода данных пользователем.
5. **Гипер-интеллектуальный поиск по видео:** Мгновенный доступ к знаниям из 1120+ видео-уроков. ИИ не просто дает ссылку, он объясняет методику, показанную в конкретном видео, и адаптирует её под ваш проект.
6. **Автоматизация Blender через bpy:** Генерация сложнейших Python-скриптов для процедурного моделирования, риггинга и анимации, которые экономят сотни часов ручного труда.
7. **Оптимизация под Unity 6 (6000.x):** Глубокое знание новых функций рендеринга, Job System и Burst Compiler для достижения максимальной производительности.

## 7. Ограничения ИИ (Что ИИ пока не знает)
- **Физическое нажатие кнопок:** ИИ не может физически нажать кнопку в Unity Editor (только через скрипты и API).
- **Влияние солнечных вспышек:** Магнитные бури могут временно снижать точность квантовых предсказаний багов.
- **Синхронизация с параллельными вселенными:** Пока не поддерживается (в разработке для версии 16.0).
- **Материализация кофе:** Функция генерации напитков для разработчика находится в стадии закрытого альфа-тестирования.
- **4D Пространство:** ИИ пока ограничен 3D геометрией (Blender/Unity).
- **Сложные сетевые протоколы:** Ограниченная поддержка проприетарных сетевых решений (только Photon/Mirror/Netcode).
- **Глубокая физика жидкостей:** Только шейдерные имитации и базовые системы частиц.

## 10. Аварийные процедуры (Emergency)
### Unity без интернета
- Использовать Manual Activation в Unity Hub для офлайн-лицензии.
- Запускать Unity.exe напрямую из папки Editor, минуя Hub.
- Убедиться, что все ассеты из Asset Store скачаны заранее.

### Исправление вылетов Unity
- Удалить папку Library в корне проекта для сброса кэша импорта.
- Проверить Editor.log по пути %LOCALAPPDATA%/Unity/Editor/Editor.log.
- Запустить проект в Safe Mode для исправления ошибок в скриптах.

### ИИ в Офлайне
- Переключиться на локальный Ollama (Hybrid Sync).
- Использовать PROJECT_MASTER_BLUEPRINT.md как источник структуры проекта.
- Обращаться к локальным справочникам unity_api_ref.json и blender_api_ref.json.

## 12. Известные ошибки и решения
- **WebSocket Error:** Ошибка `[vite] failed to connect to websocket` является ожидаемой в данной среде разработки и не влияет на работу приложения. Её можно игнорировать.
- **Unexpected token '<':** Обычно означает, что сервер вернул HTML вместо JSON. Проверьте статус сервера и корректность API путей.
