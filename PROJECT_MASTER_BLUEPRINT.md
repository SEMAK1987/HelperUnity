# PROJECT MASTER BLUEPRINT: Unity & Blender AI Assistant

> **ВНИМАНИЕ:** Этот документ является "источником истины" для всего проекта. Он содержит полную структуру интерфейса, базу знаний агентов и инструкции по восстановлению.

## 1. Общая информация
- **Версия Помощника:** 13.3.3
- **Описание:** Гибридный ИИ-помощник (Online/Offline) для Unity & Blender. Поддержка Ollama, миграция на Unity 6, сохранение чата, поддержка архивов и самовосстановление.
- **Путь проекта:** /app/applet
- **Локальное хранилище:** Настроено через knowledge_base.json
- **Версия Unity:** 2022.3.62f2 (LTS)
- **Версия Blender:** Поддержка API v2.49 - v5.1

## 2. Структура интерфейса
### Вкладки
- **STUDIO**: Главная студия разработки (Чат, Статистика, Статус ПО)
- **KB**: База знаний (API справочники, Видео-уроки)
- **COMMANDS**: Командный центр (Миграция, Конвертеры, Git LFS)
- **FILES**: Файловый менеджер (Управление ассетами)

### Компоненты
- **Sidebar**: Мини-панель навигации со статус-индикаторами (Сеть, Vision, AI Агент)
- **Top Bar**: Управление сессией, Миграция, Статус Ollama, Обновление
- **Right Sidebar**: Логи системы и статус Unity/Blender

## 3. Иерархия ИИ-Агентов (49 агентов)
### Уровень 1: Директора (Claude Opus)
- **Креативный директор**: Стратегические решения, видение проекта
- **Unity AI Assistant**: Эксперт по проекту, анализ видео и PDF
- **Технический директор**: Архитектура, разрешение технических конфликтов
- **Продюсер**: Сроки, ресурсы, управление отделами

### Уровень 2: Руководители отделов (Claude Sonnet)

### Уровень 3: Специалисты (Sonnet/Haiku)
- **Геймплей-программист**, **UI/UX-дизайнер**, **Technical Artist**, **VFX Artist**, **Animator**, **AI Programmer**

## 4. Новые возможности ИИ (v13.3.3)
- **Vision & Media (Enhanced):** ИИ полноценно анализирует скриншоты ошибок и видео-контент.
- **Optimized Uploads:** Улучшенная система загрузки файлов до 500МБ с отображением скорости (MB/s) и времени.
- **System Status API:** Новый эндпоинт `/api/system/status` для мониторинга здоровья сервера и хранилища.
- **Extended Knowledge Base:** Интеграция 151+ видео-уроков по Unity и Blender.
- **Hybrid AI (Ollama):** Бесшовная работа без интернета через локальные LLM.
- **Unity Bridge:** Автоматическая конвертация материалов Blender -> Unity URP/HDRP.

## 5. Анализ и Аудит Проекта
- **Deep Scan:** Автоматический поиск `GetComponent` в `Update`, утечек памяти и TODO задач.
- **Asset Audit:** Отслеживание тяжелых ассетов (> 10MB) и оптимизация структуры проекта.
- **Integrity Check:** Самовосстановление поврежденных файлов конфигурации.

## 6. База знаний: Системы инвентаря и ИИ
- **Инвентарь:** Слоты, Сетка (Diablo-style), Список, Кукла экипировки.
- **ИИ:** Behavior Trees, Utility AI, ML-Agents, Pathfinding.
- **Графика:** Shader Graph, VFX Graph, Ray Tracing, Volumetric Lighting.

## 7. Архитектура Offline & Hybrid
- **LLM Provider:** Ollama (localhost:11434).
- **Fallback Logic:** Автоматическое переключение на локальный API при потере связи.
- **Local Knowledge:** Использование `knowledge_base.json` и `project_stats.json` для контекста.

## 8. Аварийные процедуры (Emergency)
### Unity без интернета
- Manual Activation в Unity Hub.
- Запуск Unity.exe напрямую.
### ИИ в Офлайне
- Переключение на локальный Ollama (Hybrid Sync).
- Использование Master Blueprint как источника структуры.

## 9. Инструкции по восстановлению
1. Установите Node.js (v18+).
2. Склонируйте репозиторий.
3. Запустите `RUN.bat` или `npm start`.

## 10. Известные ошибки и решения
- **WebSocket Error:** Ожидаемое поведение в среде разработки, игнорировать.
- **Upload Speed:** Зависит от сетевой задержки. Оптимизировано через синхронный Multer Storage.
- **Unexpected token '<':** Проверьте статус сервера через `/api/system/status`.
