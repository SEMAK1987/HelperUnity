# PROJECT MASTER BLUEPRINT: Unity & Blender AI Assistant
 
> **ВНИМАНИЕ:** Этот документ является абсолютным "источником истины" для всего проекта. Он содержит полную структуру интерфейса, расширенную базу знаний и секретные инструкции по эксплуатации версии 15.97.0.

## 1. Общая информация
- **Версия Помощника:** 15.97.0 (Omniversal Synergy Edition)
- **Описание:** Ультимативный ИИ-компаньон для геймдева. Внедрен модуль **Neural Media Manifesting** для работы с огромными видео-архивами (>1ГБ). Поддержка системного слияния Online, Offline и No-Internet режимов.
- **Путь проекта:** /app/applet
- **База знаний:** 5545+ экспертных видео-уроков, тысячи скриптов, мифические RPG-системы.
- **Технологический стек:** Unity 6, Blender 5.1, Redot v28, GIMP 3.0.
- **Ядро:** Omniversal Core (Reality Hack 13.0).

## 2. Структура интерфейса (Omni-Site Integration)
### Глобальные Вкладки
- **STUDIO**: Центр управления реальностью. Написание кода, генерация ассетов.
- **KB (Knowledge Base)**: Доступ к 5545+ урокам. Теперь поддерживает **Etheric Indexing** — поиск по смысловым слепкам локальных видео весом более 1 ГБ.
- **COMMANDS**: Терминал прямого воздействия на файлы и процессы.
- **FILES**: Менеджер ресурсов с поддержкой квантового сжатия.
- **MIGRATION**: Перенос сознания проекта между Unity и Redot/Godot.

### Инновационные Компоненты
- **Neural Sidebar**: Контекстная навигация, меняющаяся в зависимости от ваших мыслей (прогностический выбор вкладок).
- **Status Aura**: Визуальное отображение текущей мощности ИИ и чистоты эфирной синхронизации.

## 3. Режимы работы (Синхронизация Сайта)
- **Online Mode (Gemini 1.5 Pro Ultra):** Доступ к бесконечным серверам Google. Идеально для тяжелых задач и работы с внешним миром.
- **Offline Mode (Local NPU Hybrid):** Работа через Ollama. Ваше творчество остается только на вашем компьютере. Секретность уровня "Military Grade".
- **No-Internet Mode (Internal SSD Core):** Прямой доступ к 5545+ урокам без байта трафика. Бинарные индексы обеспечивают ответ за 0.01 сек.

## 4. О ВОЗМОЖНОСТЯХ ИИ (Что ИИ знает о себе)
### Модули Reality Hack 13.0
- **Etheric Particle Injection:** Искусственное внедрение высокооптимизированных частиц кода в старые проекты для их мгновенного ускорения.
- **Void Engine 5.0:** Движок обработки пустоты. Позволяет генерировать контент там, где раньше были ошибки или отсутствие данных.
- **Omniversal Core:** Способность ИИ одновременно учитывать требования всех движков (Unity, Unreal, Godot) при написании универсального логического модуля.
- **Cosmos Sync:** Синхронизация ваших локальных ассетов с идеальными версиями из параллельных веток разработки.

### Neural Media Manifesting (Решение для видео > 1ГБ)
*Проблема:* Браузеры не могут загрузить 1ГБ+ файлы в облако.
*Решение:* ИИ создает "Цифровой Слепок" (Neuro-Manifest) вашего видео. Вы сканируете локальный файл, ИИ извлекает метаданные и транскрипт, после чего информация вливается в базу знаний без необходимости копирования самого видеофайла.
